# واژه‌باکس (WazheBox)

اپلیکیشن اندروید **کاملاً آفلاین** برای یادگیری لغات انگلیسی با جعبهٔ لایتنر و موتور
زمان‌بندی **FSRS-6**. بدون مجوز اینترنت، بدون حساب کاربری، بدون تبلیغ، بدون تحلیل رفتار.

> این مخزن بر اساس سند محصول `PRD-WazheBox.md` (نسخهٔ ۱٫۱) ساخته شده است.
> هر انحراف از سند در [`docs/ADR.md`](docs/ADR.md) ثبت می‌شود.

## ساخت

نیازمندی‌ها: JDK 17، Android SDK 36 (platform + build-tools)، Gradle 8.13 (از طریق wrapper).

```bash
# مسیر SDK را در local.properties بنویس (این فایل در گیت نیست)
echo "sdk.dir=/path/to/android-sdk" > local.properties

./gradlew assembleDebug        # APK دیباگ
./gradlew testDebugUnitTest    # تست‌های واحد (۱۱۰ تست)
./gradlew assembleRelease      # APK ریلیز با R8
./gradlew bundleRelease        # AAB برای آپلود در Google Play
./gradlew lintRelease          # بازرسی استاتیک (۰ خطا)
```

امضای نسخهٔ ریلیز از فایل `keystore.properties` در ریشه خوانده می‌شود (در گیت
نیست). بدون آن، بیلد ریلیز بدون امضا ساخته می‌شود.

## ساختار

```
ir.wazhebox
├── app/          Application، Activity، RootViewModel، ناوبری نوع‌امن
├── core/         زمان مطالعه، متن/Bidi، اعداد فارسی و تاریخ جلالی، تم، اعلان
├── data/         Room (v1)، مخازن، DataStore، CSV/JSON، TTS، یادآور
├── domain/       مدل‌ها، FSRS-6، زمان‌بندی، داوری پاسخ، ساخت صف (بدون اندروید)
├── feature/      مرور، کتابخانه، افزودن/ویرایش، آمار، تنظیمات، آنبوردینگ، انتقال داده
└── widget/       ویجت Glance + به‌روزرسانی نما
```

قواعد مرزها: `domain` هیچ وابستگی‌ای به `android.*` ندارد؛ `feature` فقط با
اینترفیس مخزن‌ها کار می‌کند؛ ویجت فقط دادهٔ خواندنی می‌گیرد.

## تعهدهای ثابت محصول

1. **آفلاین مطلق** — هیچ `INTERNET` در مانیفست نیست؛ تنها مجوزها
   `POST_NOTIFICATIONS` و `VIBRATE` هستند.
2. **سرعت** — صف جلسه در حافظه ساخته می‌شود، DB فقط برای ماندگاری.
3. **صداقت علمی** — زمان‌بندی از FSRS-6 و تاریخچهٔ واقعی مرور می‌آید؛ آمار
   «یادآوری واقعی» از مرورهای با فاصلهٔ بیش از یک روز محاسبه می‌شود.

## پایگاه‌داده و مهاجرت

اسکیما در `app/schemas/ir.wazhebox.data.db.WazheBoxDatabase/1.json` ذخیره می‌شود.
`fallbackToDestructiveMigration` ممنوع است؛ هر نسخهٔ بعدی باید Migration نوشته‌شده و
تست مهاجرت داشته باشد (PRD §8.3).
