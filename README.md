# واژه‌باکس (WazheBox)

اپلیکیشن اندروید **کاملاً آفلاین** برای یادگیری لغات انگلیسی با جعبهٔ لایتنر و موتور
زمان‌بندی FSRS-6. بدون مجوز اینترنت، بدون حساب کاربری، بدون تبلیغ.

> این مخزن بر اساس سند محصول `PRD-WazheBox.md` (نسخهٔ ۱٫۱) ساخته می‌شود.
> هر انحراف از سند در `docs/ADR.md` ثبت می‌شود.

## ساخت

نیازمندی‌ها: JDK 17، Android SDK 36 (platform + build-tools)، Gradle 8.13 (از طریق wrapper).

```bash
# مسیر SDK را در local.properties بنویس (این فایل در گیت نیست)
echo "sdk.dir=/path/to/android-sdk" > local.properties

./gradlew assembleDebug        # ساخت APK دیباگ
./gradlew testDebugUnitTest    # تست‌های واحد (زمان‌بندی، داوری، داده)
./gradlew lintDebug            # لینت
```

## ساختار

```
ir.wazhebox
├── app/          Application، Activity، ناوبری
├── core/         زمان مطالعه، متن/Bidi، تم و کامپوننت‌های مشترک، اعلان
├── data/         Room، مخازن، DataStore، CSV/JSON، TTS
├── domain/       مدل‌ها، زمان‌بندی FSRS، داوری پاسخ (بدون وابستگی به اندروید)
├── feature/      صفحه‌های مرور، کتابخانه، افزودن، آمار، تنظیمات، آنبوردینگ
└── widget/       ویجت Glance
```

## تعهدهای ثابت محصول

1. **آفلاین مطلق** — هیچ `INTERNET` در مانیفست نیست.
2. **سرعت** — کارت بعدی زیر ۱۰۰ms، شروع سرد زیر ۱٫۲ ثانیه.
3. **صداقت علمی** — زمان‌بندی از FSRS-6 و دادهٔ واقعی مرور کاربر می‌آید.
